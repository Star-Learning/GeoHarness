# GeoHarness Analysis Topics

Analysis Topics 使用真实 Harness Agent、真实 GIS Tools 和真实数据录制完整专题流程；与
`examples/scenarios/*` 的确定性回归案例分开存放。

- [`01-historic-building-renewal`](01-historic-building-renewal/README.md)：曼哈顿历史建筑更新优先区，多约束筛选、面积计算、分区聚合与导出。
- [`02-firehouse-coverage`](02-firehouse-coverage/README.md)：下曼哈顿消防覆盖盲区，多工具矢量分析、独立 oracle 与真实录制。
- [`03-satellite-visual-inspection`](03-satellite-visual-inspection/README.md)：当前卫星 RGB 底图视觉巡检，输出像素初筛蒙版、统计和明确限制。
