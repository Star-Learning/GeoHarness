# 卫星影像视觉巡检 Agent

请先在 GeoHarness 地图工具栏点击 `AI`，显式允许当前地图视野保存到本地 Session；然后只分析当前
地图视野中正在显示的卫星 RGB 影像，不加载或使用任何建筑、道路、行政区等矢量数据。

请先说明你将执行的是视觉初筛，不是多光谱遥感反演。然后调用
`inspect_satellite_view`，检查以下四类视觉地物：

- water
- vegetation
- built_up
- bare_ground

使用 Tool 返回的当前视野范围、瓦片层级、实际处理像素数、显示像素占比和启发式置信度形成报告。
地图上应展示 Tool 生成的彩色 Overlay。报告必须逐项说明数据来源、RGB/边缘规则、分类结果和不确定性，
不得把显示像素占比写成真实面积，不得声称计算了 NDVI、地表覆盖精确分类或多时相变化。

如果当前地图视野尚未同步或卫星瓦片不可用，请明确报告失败原因，不得回退到预设统计值。
