# Agent Video Prompt

新建一个空 Harness 会话，仅发送下面这条输入。

```text
请自主找到当前目录中来源可审计的 NYC 官方 Lower Manhattan 建筑轮廓快照，并完成一次完整检查。请报告发布方、数据集标识、快照日期、要素数量、坐标系、几何类型、空间范围、无效几何数，以及屋顶高度和建成年份字段的缺失情况与分布；再在适合纽约的米制投影中计算每栋建筑占地面积和总占地面积。把被检查的官方建筑及面积派生图层显示在地图上，最终用简洁中文总结数据质量、屋顶高度、最早与最晚建成年份和继续分析时的注意事项。所有数字和结论必须来自本轮真实 Tool Result，不要读取或复述预设答案。
```

录制重点：官方来源元数据、质量检查、面积计算、年份与高度统计、地图要素检查和最终结论。
