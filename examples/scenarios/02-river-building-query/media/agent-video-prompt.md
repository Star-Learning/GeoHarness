# Agent Video Prompt

新建一个空 Harness 会话，仅发送下面这条输入。

```text
请使用当前可访问的真实 NYC 官方数据，找出 Manhattan 中距离 Hudson River 或 East River 500 米以内的建筑。请自主发现并选择正确的数据和 GIS 工具，距离计算必须使用适合纽约的米制投影，不能把 500 米替换成任何默认值。地图上逐步保留建筑、河流、500 米缓冲范围和最终筛选建筑；最后报告输入建筑数、命中建筑数、实际距离、单位、坐标系、数据来源和快照日期。请根据本轮 Tool Result 给出结论，不要调用固定 Scenario 或预设答案。
```

录制重点：河流与建筑载入、500 米缓冲、空间筛选、图层逐步出现、结果计数和地图缩放。
