# Agent Video Prompt

新建一个空 Harness 会话，仅发送下面这条输入。

```text
请使用当前可访问的官方 Manhattan Community District 边界和建筑数据，自主规划并完成分区统计。为每个行政区统计建筑数量和建筑占地面积总和；面积必须在合适的米制投影中计算。地图上展示原始建筑、行政区边界以及带统计字段的派生行政区图层。最终按建筑数量从高到低输出一张中文表格，列出行政区、建筑数和总占地面积，并说明未能归入任何行政区的建筑数、所用坐标系、数据来源和快照日期。所有数值必须引用本轮真实 Tool Result，不要套用预设流程或答案。
```

录制重点：双数据集发现、空间关联、面积聚合、行政区专题图层、表格结果和要素检查。
