# Agent Video Prompts

新建一个空 Harness 会话。先发送“第一轮”，待其完整结束后，在同一个会话发送“第二轮”。

## 第一轮

```text
请使用当前可访问的真实 NYC 官方数据，找出距离 Broadway 500 米以内的 Manhattan 建筑。请自主发现数据、识别 Broadway、选择 GIS 工具并使用适合纽约的米制投影。地图上逐步保留 Broadway、500 米缓冲范围和候选建筑，最终报告输入建筑数、命中建筑数、实际距离、单位、坐标系、数据来源和快照日期。所有结果必须来自本轮真实 Tool Result，不要使用固定 Scenario 或预设答案。
```

## 第二轮

```text
把刚才的分析距离改成 200 米。请理解并复用同一会话中仍然有效的数据与中间结果，只重新执行受距离变化影响的步骤；地图上的缓冲范围和候选建筑必须更新为 200 米。最后对比修改前后的命中数量，并明确说明哪些数据或步骤被复用、哪些步骤重新执行，以及本轮实际使用的距离、单位和坐标系。不要重新套用预设示例，所有数字以真实 Tool Result 为准。
```

录制重点：同一会话两轮执行、500 米结果、第二轮输入、200 米局部重算、图层替换与前后对比。
