# Agent Video Prompt

新建一个空 Harness 会话，仅发送下面这条输入。

```text
请使用当前可访问的真实 NYC 官方道路、河流和建筑数据，找出同时满足以下两个条件的 Manhattan 建筑：距离 Broadway 不超过 300 米，并且距离 Hudson River 或 East River 至少 800 米。请自主规划两个空间约束的执行顺序，使用适合纽约的米制投影精确计算，不要改变 300 米和 800 米参数。地图上逐步保留 Broadway、河流、两个距离范围、中间候选图层和最终交集；最后分别报告每个条件筛选后的数量、同时满足两个条件的数量、输入建筑数、坐标系、数据来源和快照日期。所有数字必须来自本轮真实 Tool Result，不要套用固定 Scenario 或预设答案。
```

录制重点：两个独立空间条件、中间候选、最终交集、图层显隐、地图缩放和计数核对。
