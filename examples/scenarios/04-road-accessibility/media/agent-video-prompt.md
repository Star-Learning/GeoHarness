# Agent Video Prompt

新建一个空 Harness 会话，仅发送下面这条输入。

```text
请从当前可访问的 NYC 官方道路数据中识别 Broadway，找出距离 Broadway 300 米以内的 Manhattan 建筑，并按 Community District 统计这些候选建筑的数量。请自主选择数据和 GIS 工具，使用适合纽约的米制投影精确计算 300 米距离。地图上逐步保留 Broadway、300 米缓冲范围、候选建筑、行政区边界和分区统计结果；最后报告检查建筑数、候选建筑总数、各行政区数量、无法归区的数量、距离单位、坐标系、数据来源和快照日期。请只根据本轮真实 Tool Result 作答，不要套用固定示例。
```

录制重点：道路属性筛选、300 米缓冲、候选建筑、分区统计、图层联动和最终表格。
