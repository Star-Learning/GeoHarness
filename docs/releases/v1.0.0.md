# GeoHarness v1.0.0

GeoHarness v1.0.0 把已验证的 Agentic GIS Demo 完善为基于 DeepSeek Harness 的本地优先矢量 GIS Agent 平台。用户可以在原生 Harness 项目与会话中上传自己的空间数据，用自然语言驱动真实 GIS Tools，并在地图、图层、运行记录和 Result Center 中核查、修订与导出结果。

## 本版本做实的能力

- GeoJSON、Shapefile ZIP、GeoPackage、CSV 经纬度四种用户数据导入；
- Session 隔离、可恢复的 Workspace、canonical Layer 和 lineage；
- 13 个 catalog 驱动的 Harness Tools 与 Native Agent 流式事件；
- 数据质量、属性表、地图选择、图层偏好和滚轮缩放；
- 距离、谓词、属性值、导出格式和追加空间条件的同会话修订；
- 最终回答、真实统计、来源、警告、三格式资产和 Run Manifest 的 Result Center；
- 有界上传、ZIP/路径防护、超时/取消、失败回滚、幂等、分页和脱敏诊断；
- Tool/Dataset `1.0` 扩展契约与缺失能力显式报告。

## 发布验收

- 三个非预设用户上传 E2E：133 栋建筑质量检查、主要道路任意 275 米筛选 241 栋建筑、360 栋建筑按三区域聚合与导出；
- 每个空间结果均由独立 GeoPandas/Shapely oracle 核对；
- 七个官方 NYC Scenario 的数据、测试和 Demo 回归继续通过；
- Windows 与 Ubuntu CI 覆盖 Node `22.19.0` / `24`、Python 3.11；
- 全新 `DSH_HOME` 的插件安装、随机端口启动、HTTP 探测、卸载在 Windows/Linux 执行。

## 安装

```sh
git clone https://github.com/Star-Learning/GeoHarness.git
cd GeoHarness
pnpm install
python -m pip install -e "./backend/geo-service[test]"
pnpm run build
npx @deepseek-ai/dsh@0.1.1-rc.2 plugin --profile web add ./bundle/geoharness-bundle
npx @deepseek-ai/dsh@0.1.1-rc.2 web
```

在 Harness 左下角原生设置中配置 Provider、模型和 API Key，然后新建会话、上传数据并输入 GIS 需求。卸载命令：

```sh
npx @deepseek-ai/dsh@0.1.1-rc.2 plugin --profile web remove @geoharness/harness-plugin
```

## 边界

v1.0 只提供矢量 GIS 能力，不包含栅格、路网等时圈、3D、点云、多租户或 Marketplace。Agent 遇到缺失能力时必须明确说明，不得伪造 Tool Result、Layer 或统计。完整环境和边界见[兼容矩阵](compatibility-matrix.md)，架构与安全细节见[开发文档导航](../README.md)。
